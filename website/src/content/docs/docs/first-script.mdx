A script is a text file of Skript code. This one greets players when they join and adds a `/hello` command. It takes a few minutes, and needs a server with NeoSkript [installed](/docs/install/) and a text editor.

## Write it

<Steps>

1. In `plugins/NeoSkript/scripts/`, make a file called `hello.sk`.

2. Put this in it:

   ```skript title="hello.sk"
   on join:
   	send "<gold>Welcome to the server, %player%!" to player

   command /hello:
   	description: Says hello.
   	trigger:
   		send "<green>Hello, %sender%!" to sender
   ```

   The lines under `on join:` and `trigger:` are indented, with tabs or spaces. Indentation is how Skript knows which lines belong to what.

3. Save it, and in the game or the console run:

   ```text
   /sk reload hello
   ```

   You'll see `Successfully reloaded hello.sk.` and how long it took. Join the server, or run `/hello`, and the script answers.

</Steps>

## What it does

- `on join:` is an **event**. Its code runs each time a player joins.
- `send "..." to player` is an **effect**: a line that does something. `player` is the player who joined.
- `%player%` in the text is replaced by the player's name. Anything between `%` signs is a value.
- `<gold>` and `<green>` are colours.
- `command /hello:` adds a **command**. Its code goes under `trigger:`, and `sender` is whoever ran it.

## Add a variable

Variables keep values. One in curly brackets without `_` at the start is saved, so it's still there after a restart. Change `hello.sk` to count joins:

```skript title="hello.sk"
on join:
	add 1 to {joins::%player's uuid%}
	send "<gold>Welcome, %player%! That's visit number %{joins::%player's uuid%}%." to player

command /hello:
	description: Says hello.
	trigger:
		send "<green>Hello, %sender%!" to sender
```

`{joins::%player's uuid%}` is a different variable for each player, named by their UUID. Run `/sk reload hello` again.

## Fix an error

Change `send` to `sned` on the third line, save, and reload. The script doesn't load that line, and NeoSkript says why:

```text
Line 3: (hello.sk)
    Can't understand this condition/effect: sned "<gold>Welcome, %player%! That's visit number %{joins::%player's uuid%}%." to player
    Line: sned "<gold>Welcome, %player%! That's visit number %{joins::%player's uuid%}%." to player
```

The version that was running keeps running until the new one loads without errors. Change it back and reload.

<Aside type="tip">
You don't need a server to find errors: paste a script into [the parser](/parser/), or install the [editor extension](/docs/editors/), and errors show as you type.
</Aside>
