<Steps>

1. Check your server runs **Paper or Folia, Minecraft 1.21.4 to 26.3, on Java 21 for 1.21.x or Java 25 for 26.x**.

2. Get the jar from [Modrinth](https://modrinth.com/plugin/neoskript) or [the download page](/download/).

3. If Skript is installed, take `Skript.jar` out of `plugins/`. NeoSkript won't start next to Skript: they'd fight over the same scripts and the same `/skript` command. Leave the `plugins/Skript` folder where it is; see [moving from Skript](/docs/moving-from-skript/).

4. Put the NeoSkript jar in `plugins/` and start the server.

</Steps>

The console says it's running, and how many scripts it loaded:

```text
[NeoSkript] NeoSkript 0.1.0-beta.1 enabled on Paper 26.3
[NeoSkript] Loaded 0 variables in 2 ms
[NeoSkript] Loaded 0 scripts with 0 triggers in 1 ms
```

## Where things go

<FileTree>
- plugins/
  - NeoSkript-0.1.0-beta.1.jar
  - NeoSkript/
    - config.yml settings, written on the first start
    - variables.csv saved global variables
    - scripts/ your .sk files
</FileTree>

Scripts go in `plugins/NeoSkript/scripts/`, as `.sk` files, like Skript's. `/sk reload <script>` reloads one, and `/sk help` lists the rest; `/skript`, `/neoskript` and `/ns` work too. See [commands](/docs/server/commands/). New to Skript? Start with [your first script](/docs/first-script/).

## Configuration

`plugins/NeoSkript/config.yml` is written on the first start, with a comment on every setting. It starts with a theme for NeoSkript's messages, then covers where variables are saved, the event priority scripts listen at, how runtime errors are rate-limited, effect commands, the update checker, which tells you about newer versions on Modrinth (`update-checker: false` turns it off), and bStats, which you can turn off with `metrics: false`. Every setting is on the [configuration](/docs/server/configuration/) page.

<Aside type="tip">
Development builds of every change on main are on the [download page](/download/) and [GitHub](https://github.com/xena-studios/neoskript/releases/tag/dev). Use them on a server you can afford to break.
</Aside>
