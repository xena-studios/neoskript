`/sk reload <script>` reads a script again and swaps the new version in, without restarting the server. `/sk reload scripts` does every script.

## A script with errors

NeoSkript reads and compiles everything first, then switches over together. If a script has errors, they're reported and **the new version loads without what has them**, as on Skript: a line that fails is left out and the code around it runs, and a section, trigger or function whose header fails is left out whole. [Reading errors](/docs/scripts/errors/#where-errors-appear) has what's left out for each kind of line. Fix the errors and reload again.

<Aside type="note">
NeoSkript used to keep the old version of a script whose new version had errors. That isn't what Skript does, and scripts written for Skript expect the rest of the script to run, so a reload now matches Skript. If NeoSkript itself fails to compile part of a script (a bug, not a mistake in the script), that script keeps the version that was running, and the error says so: `The version that was running keeps running.`
</Aside>

Functions keep working across reloads too: a trigger that calls a function from another script calls its new version once that script reloads.

## What happens on a reload

- `on unload` triggers of the old version run, then `on load` triggers of the new one.
- The script's commands are replaced, and players get the new command list straight away.
- `every` timers start again.
- Global variables aren't touched: they're not part of the script.

The benchmark on the [performance](/docs/server/performance/) page reloads 40 scripts, 5,960 lines, in 228 ms, against 1,412 ms on Skript.

## Who hears about it

The player who reloads gets a report: what was reloaded, how many scripts, how long it took, and each script's problems with their line numbers. Players with `skript.reloadnotify` are told who's reloading what, and get the same report.

```text
[NeoSkript] Reloading shop.sk...
 shop.sk - 1 error
   Line 14: Can't understand this condition/effect: sned "hi" to player
     sned "hi" to player
[NeoSkript] Reloaded shop.sk with 1 error in 3 ms. What has errors is left out.
```

In chat, hovering over a problem shows the line of code, and clicking copies it. The look comes from the [theme](/docs/server/configuration/#make-it-look-like-your-server) in `config.yml`. See [reload reports](/docs/server/commands/#reload-reports).

## auto reload

A script with an `auto reload` structure reloads itself when its file changes, checked every 2 seconds. A version with errors loads without what has them, as with `/sk reload`.

```skript
auto reload:
	recipients: "Notch" and "jeb_"
	permission: skript.reloadnotify

on join:
	send "Hello!" to player
```

The console and the listed recipients get each reload's report. Without `recipients:`, players with the `permission:` hear, `skript.reloadnotify` by default. `auto reload` alone, with no entries, works too.
